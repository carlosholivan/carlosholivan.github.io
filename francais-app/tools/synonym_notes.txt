# mot1 / mot2 = nota en español (palabras que se confunden)
connaître / savoir = connaître: conocer (personas, lugares, cosas); savoir: saber (un dato, una información; savoir + infinitivo = saber hacer).
visiter / rendre visite = visiter: visitar un lugar (un musée, une ville); a una persona se le hace una visita: rendre visite à quelqu'un.
le jour / la journée = le jour: el día como unidad o fecha (trois jours, quel jour) · la journée: el día en su duración, lo que pasa en él (bonne journée, toute la journée).
l'an / l'année = l'an con números (vingt ans, deux ans) · l'année cuando se piensa en su duración o va con adjetivo (toute l'année, l'année dernière, une bonne année).
le soir / la soirée = le soir: la tarde-noche como momento (ce soir) · la soirée: su duración, o una fiesta (une soirée chez des amis).
le matin / la matinée = le matin: la mañana como momento · la matinée: su duración (toute la matinée).
regarder / voir = regarder: mirar (con intención); voir: ver (percibir). On regarde un film, on voit quelqu'un dans la rue.
écouter / entendre = écouter: escuchar (con atención); entendre: oír.
le fils / la fille / le garçon = le fils: hijo · la fille: hija o chica · le garçon: chico (y también camarero, algo anticuado).
la chance / la fortune = la chance: la suerte (avoir de la chance) · la fortune: una gran riqueza.
le médecin / le médicament / la médecine = le médecin: el médico · le médicament: el medicamento · la médecine: la medicina como ciencia o estudios.
prêter / emprunter = prêter: prestar (dar) · emprunter: pedir prestado (recibir). Je te prête mon livre / J'emprunte ton livre.
apporter / emporter / amener / emmener = apporter / emporter: traer / llevarse cosas · amener / emmener: traer / llevar a personas o animales.
quand / lorsque = Los dos significan «cuando»; lorsque es más formal y escrito, y nunca es interrogativo.
le patron / le chef = le patron: el jefe, el dueño de un negocio · le chef: el jefe de un equipo, o el jefe de cocina.
sensible / sensé = sensible: sensible (≠ sensato) · sensé: sensato. Falso amigo: sensible no significa «sensato».
la carrière / la course = la carrière: carrera profesional · la course: carrera (deporte) o compra (faire les courses). La carrera universitaria se dice les études.
louer / la location = louer: alquilar (y también alabar) · la location: el alquiler (no «localización»).
le rapport / la relation = le rapport: informe, o relación entre cosas (par rapport à) · la relation: relación entre personas.
le regard / la vue = le regard: la mirada (de alguien) · la vue: la vista (sentido, o lo que se ve desde un sitio).
assister / aider = assister à: asistir a (estar presente) · aider: ayudar. Falso amigo parcial: assister quelqu'un también es ayudar (formal).
la pensée / l'avis = la pensée: el pensamiento · l'avis: la opinión (à mon avis).
la tâche / la tache = la tâche (con acento): la tarea · la tache: la mancha.
le tort / la faute = avoir tort: no tener razón · la faute: la culpa o el error (c'est ma faute, une faute d'orthographe).
la grève / la plage = la grève: la huelga (y, en literatura, la orilla de arena) · la plage: la playa.
amener / emmener = amener: traer a alguien hasta aquí · emmener: llevarse a alguien de aquí a otro sitio.
